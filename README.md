# 流星弹幕（MeteorDanmaku）

这是一个用于 GitHub Pages 的前端演示项目，把仓库改造成一个简单的弹幕视频网站前端（仅前端示例）。

主要文件：

- index.html — 页面与视频播放器、弹幕层与控制面板
- styles.css — 样式文件
- app.js — 弹幕逻辑：发送、样式、定时弹幕与基本控制

功能亮点：

- 实时发送弹幕（支持颜色、字号、速度和透明度）
- 自动示例弹幕按视频时间点回放
- 支持隐藏/显示与清空弹幕
- 兼容桌面与移动浏览器（响应式）

如何使用：

1. 打开仓库的 GitHub Pages（此仓库已启用 Pages）或直接在浏览器中打开 `index.html`。
2. 点击播放视频，然后在输入框中输入弹幕并发送。
3. 使用颜色选择器与滑块调整样式与速度。

后续改进建议（可选）：

- 持久化弹幕（本地或后端存储）与与视频时间同步的弹幕文件（如 .ass/.json）
- 弹幕轨道管理，避免重叠
- 弹幕过滤与用户管理（屏蔽词/举报）
- 支持滚动/顶部/底部等多种弹幕样式
